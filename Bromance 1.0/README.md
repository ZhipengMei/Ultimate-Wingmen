# *Bromance*
**Bromance**: The Ultimate Wingman App

Time spent: **10** hours spent in total

## User Stories

The following **required** functionality is complete:

- [ ] User can view a list of nearby users within 20 miles radius
- [ ] User can chat with nearby users

The following **optional** features are implemented:

- [x] Store current user location with GeoFire
- [x] Retrieve nearby users' location (added as marker on google map)
- [x] Transparent circle centered at the user's current location
- [x] User sign in with other social media account
- [x] User creation with email (along with update username)
- [ ] User can pull to refresh to update current location and view nearby user.
- [ ] User sees a loading state while waiting for the Google Map API.


The following **additional (unlocked)** features are implemented:
- [ ] Search interface: view worldwide user region based search
